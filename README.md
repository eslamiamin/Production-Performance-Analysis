# Production & Packaging Performance Monitoring Dashboard

> Portfolio version of a BI project developed for monitoring Production and Packaging performance in an Iranian food industry company.

## About the Project

This project focused on developing a performance monitoring system for Production and Packaging operations in an Iranian food industry company.

The dashboard was developed in **Persian** and designed for use by operational and senior management teams.

Due to data confidentiality requirements, the data included in this portfolio version has been modified from the original company data. Numerical values have been adjusted using randomized scaling factors so that actual business figures cannot be identified or reconstructed.

The modifications affect the absolute values of the data, but the overall trends, relationships between variables, KPI logic, and analytical structure have been preserved to demonstrate the approach used in the original implementation.

## Overview

The main challenge was not the dashboard itself. Production data was initially collected through a combination of manual Excel files and ERP records, with inconsistent data entry and discrepancies between Production, Warehouse, and Sales data.

The project therefore started with improving the underlying data structure and validation process before developing the BI layer.

## Project Scope

The project covered:

* Structuring production and packaging data
* Improving data entry processes and standards
* Validating and reconciling data across departments
* Defining and modeling operational KPIs
* Developing a Persian Power BI dashboard
* Supporting performance evaluation and incentive design

## Data Foundation & Governance

Worked with the ERP and systems teams to improve how production data was recorded and maintained.

Key activities included:

* Reviewing existing data entry processes
* Identifying inconsistent and incomplete records
* Redesigning parts of the data entry workflow
* Defining more consistent data entry rules
* Supporting adoption of the revised process within Production and Packaging

The ERP system used in the original implementation was Rahkaran.

## Data Validation & Reconciliation

Before using the data for performance analysis, production figures were continuously checked against related datasets.

The validation process included reconciliation between:

* Production output
* Warehouse inventory
* Sales data

Missing, inconsistent, and incorrect records were identified and investigated throughout the project.

This process was repeated over several months to improve the reliability of the KPIs.

## KPI Modeling

The dashboard included operational and productivity metrics such as:

* Overall Production Productivity
* Partial Productivity for two separate teams
* Healthy Output Rate
* Defect Rate
* Rework / Recycled Rate
* Production Plan Achievement Rate
* Man-Hour and Man-Shift productivity metrics

KPI definitions were reviewed and refined based on operational feedback and validation results.

## Dashboard Development

A Persian, executive-level Power BI dashboard was developed to provide a consistent view of production and packaging performance.

The dashboard focused on:

* Performance trends over time
* Plan vs. actual production
* Productivity indicators
* Quality and defect metrics
* Team-level performance
* Labor efficiency

The reports were used in senior management meetings and provided a data-based foundation for performance evaluation and incentive planning.

## Key Outcomes

* Improved the structure and reliability of production data
* Reduced discrepancies between Production, Warehouse, and Sales records
* Standardized operational performance indicators
* Created a consistent framework for performance monitoring
* Supported data-driven performance evaluation and incentive design
